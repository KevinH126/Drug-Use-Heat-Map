
# Interactive Visualization of Drug Use in the U.S.

This project is an interactive data visualization tool developed to explore and analyze drug use disorders across various regions in the United States. Built using Java and Processing, the application processes over 2,000 data points to create dynamic heat maps and visualizations that highlight regional variations and trends in drug use. The tool also includes interactive features such as year-by-year comparisons and the ability to toggle between different age groups, providing a comprehensive view of the data.


## Features

- **Dynamic Heat Map**: Visualizes drug use disorder data across U.S. regions, identifying key regional variations.

- **Interactive Visualizations**: Allows users to explore drug use trends interactively.

- **Year-by-Year Comparisons**: Enables users to compare drug use statistics across different years.

- **Age Group Toggle**: Includes buttons to switch between visualizations for different age groups.

- **Data Accuracy**: Utilizes datasets from CORGIS to ensure accurate and comprehensive representation of statistics.
## Tech Stack

- **Java**: Core programming language used for data processing and logic.

- **Processing**: Framework for creating interactive visualizations and handling user input.

- **CORGIS Dataset**: Provides the foundational data for drug use statistics.
## Data Sources
The project uses datasets from **CORGIS** (Collection of Really Great, Interesting, Situated Datasets) to ensure the accuracy and comprehensiveness of the drug use statistics. The datasets include information on drug use disorders across different U.S. regions, age groups, and years.
